API интеграций

Федерация создаёт токен в разделе «ФСП ID и API». Передавайте его в заголовке Authorization: Bearer TOKEN.

GET /api/integrations/events   — events:read
GET /api/integrations/results  — results:read
POST /api/integrations/results — results:write
{"event":"EVENT_ID","scores":[{"person":"PERSON_ID","score":300}]}

Импорт проверяет допуск, коллегию и отсутствие опубликованного протокола. Повторная публикация запрещена.
